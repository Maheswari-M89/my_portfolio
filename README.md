# Maheshwari.M — Personal Student Portfolio

A unique, modern, and warm personal student portfolio website crafted with **React** and **Tailwind CSS**, featuring a bespoke **Midnight Plum & Soft Gold** dark palette.

---

## 🎨 Theme & Palette

- **Deep Midnight Plum (`#110D1A`)**: Base background providing depth without harsh pure blacks.
- **Layered Dark Purple Surfaces (`#1B1426` & `#251C34`)**: For glassmorphic cards, headers, and interactive containers.
- **Soft Violet (`#C084FC`)**: Main accent for buttons, borders, active indicators, and interactive hovers.
- **Warm Gold (`#FBBF24`)**: Used selectively for academic achievements, milestones, and high-affinity skills.
- **Soft White (`#F8FAFC`)**: High-contrast, clean primary typography.
- **Muted Lavender-Gray (`#A8A0B5`)**: Readable, low-eye-strain secondary text.

## 🚀 Sections Included

1. **Floating Frosted-Glass Navigation Bar**:
   - Fixed header with backdrop blur (`backdrop-blur-md`).
   - "Maheshwari.M" monogram logo with warm gold accent dot.
   - Smooth navigation links: **About**, **Projects**, **Skills**, **Campus Journey**, and **Contact**.
   - Responsive mobile navigation drawer with animated open/close state.

   - Animated status badge: *"Student Developer • Learning, Building & Growing"*.
   - Headline: *"Hey, I'm Maheshwari.M — Turning Curiosity Into Creations."*
   - Electronics and Communication Engineering student bio at **K.S. Institute of Technology, Bengaluru**.
   - Action buttons: *"Explore My Journey"* & *"View My Projects"*.

3. **About Section**:
   - Narrative of bridging hardware (circuits, microcontrollers, VLSI) and modern software (Python, AI, React).
   - Core strengths checklist & KSIT academic credentials card.
4. **Skills & Capabilities**:
   - Filterable tabs across Languages & Core, Web Development, Embedded & Hardware, and VLSI & AI Tools.
   - Highlight badges with warm gold affinity indicators.
5. **Projects & Prototypes**:
   - Filterable real-world projects:
     1. *Smart IoT Environmental & Health Telemetry Node* (ESP32, MQTT, Python)
     2. *AI Vision-Based Surface Defect Inspection System* (OpenCV, Python)
     3. *4-Bit Synthesizable Arithmetic Logic Unit* (Verilog HDL)
     4. *Responsive Engineering Knowledge Hub & Portal* (React, Tailwind CSS)
     5. *Autonomous Multi-Sensor Obstacle Navigating Rover* (Arduino, C++)
   - Interactive modal popup with architectural deep dive and key outcomes.
6. **Campus Journey (KSIT Bengaluru)**:
   - Chronological academic timeline highlighting growth from Year 1 circuit foundations to final year capstone development.
7. **Contact & Connect**:
   - Interactive feedback form with state handling.
   - Direct email, campus location, GitHub, LinkedIn, and dynamic Resume download.
8. **Footer**:
   - Minimalist midnight plum footer with quick navigation links and "Back to top" button.

## 🛠️ How to Run Locally

### Prerequisites
- Node.js (v18+)

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
Generates production-ready static assets in `/dist`.
